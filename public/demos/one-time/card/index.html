Sandbox Test Values

Card Number / Expiration / CVV are Hosted Fields — Braintree blocks programmatic fill into them by design, so those rows copy to clipboard instead. Amount / ZIP / Street are plain inputs, so those rows click-to-fill directly.

Any expiration in the future + any 3-digit CVV (4-digit for Amex) works with these.
Verification ≠ transaction — these fail card verification (Vault/recurring), not a one-time sale.
These click-to-fill the Amount field — transaction success is amount-driven, not card-driven.
Only triggers a rejection if AVS/CVV rules are enabled on the merchant account. ZIP click-fills; CVV copies (Hosted Field).
Any amount — creates a settled sale that's instantly disputed (triggers webhook + email if configured).
